# AGENTS.MD — FACET-II Injector ML Model (Screen 571, Deployable Package)

## Scope

This is the **deployable inference package** for the screen-571 covariance model. It contains only trained model artifacts and a LUME-Torch interface — no training code, no datasets, no analysis scripts.

**Training and development code lives in**: `../modeling-571-moredata/modeling-571-moredata/`

## What This Package Does

Predicts the full 6x6 beam covariance matrix and (optionally) 6 phase-space means at screen 571 from 19 accelerator control parameters. The model was trained on Impact-T simulation data with alive-particle and beam-quality filtering.

- **Inputs**: 19 scalar parameters (machine PVs or simulator parameters)
- **Outputs**: 6x6 covariance matrix; optionally 6 phase-space means (mean_x, mean_px, mean_y, mean_py, mean_t, mean_pz)
- **Interface**: `from facet2_inj_ml_model_571 import load_model`
- **Variants**: `load_model()` (cov-only), `load_model(full=True)` (cov + means), `load_model("sim")` (sim inputs)

## For Agents

- **Do not modify model artifacts** in `resources/` directly. They are generated by the training pipeline in `../modeling-571-moredata/modeling-571-moredata/` and copied here after retraining.
- The `training.py` module allows retraining from prepared CSV splits but does NOT include dataset generation, target extraction, or filtering logic.
- The `train` compatibility alias in `__init__.py` exists for `torch.load()` to resolve `train.CovarianceSurrogateModel` from serialized checkpoints. Do not remove it.
- Custom lume-torch subclasses in `lume_model_utils.py` handle mixed output types (NDVariable for the 6x6 matrix + ScalarVariable for means). These are tightly coupled to the YAML model definitions.
- `BeamOutputModel` wraps the surrogate to produce openPMD `ParticleGroup` distributions from predicted covariance. It depends on `distgen`.
- See `README.MD` for the full API, input/output variable names, M-normalization details, architecture, and usage examples.
